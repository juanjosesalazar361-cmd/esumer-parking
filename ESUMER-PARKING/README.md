# ESUMER PARKING

Sistema web de gestión de parqueaderos de la Universidad ESUMER (React + Vite + Node.js + Express).

## Iniciar todo (frontend + backend)

Abre esta carpeta en VS Code, abre la terminal y escribe:

```
npm run abrir
```

(En la terminal CMD también funciona escribiendo solo `abrir`; en PowerShell: `.\abrir`.)

La primera vez instala las dependencias solo. Luego abre http://localhost:5173.
Para apagar todo: Ctrl + C.

Admin de demostración: `admin@esumer.edu.co` / `admin123`.

## Estructura
`frontend/` (React) · `backend/` (Express) · `abrir.js` (arranque de todo).
Los datos están en memoria; la base de datos (PostgreSQL) viene en la etapa 2.
