# ESUMER Parking – Backend (Express + PostgreSQL)

1. Copia `.env.example` como `.env` y pon tu `DATABASE_URL`.
2. `npm install` y `npm run dev` (o desde la carpeta raíz: `npm run abrir`).

Las tablas (`src/data/schema.sql`) y los datos iniciales (80 espacios y el administrador) se crean solos al encender.
